## Deskripsi

Lanjutan dari branch main. Sebelumnya halaman todo ini masih statis, semua tugasnya
ditulis langsung di HTML dan nggak ada yang bisa diklik. Sekarang ditambah file
script.js, jadi tugasnya bisa ditambah, diedit, dihapus, sama ditandai selesai tanpa
reload halaman.

File yang ada:

- index.html
- style.css
- script.js

## Yang dikerjakan

- Nambah tugas lewat form, kartunya langsung muncul di daftar
- Tiap kartu ada checkbox, tombol Edit, sama tombol Hapus
- Data tugas disimpan sebagai array of object di script.js
- Kalau halaman direfresh datanya balik ke 5 tugas awal, nggak pakai localStorage
- Semua tombol pakai addEventListener
- Tombol Mode Gelap buat ganti tema
